ГРУМИ ЗОВЁТ — установка как приложения (PWA)
=============================================

ЧТО ВНУТРИ
  index.html            само приложение
  manifest.webmanifest  название, цвета, иконки (для установки на экран)
  sw.js                 работа без интернета и обновления
  icons/                иконки Груми

1. ВЫЛОЖИТЬ НА GITHUB PAGES
  1) Создайте публичный репозиторий, например grumi.
  2) Add file -> Upload files: загрузите ВСЁ содержимое этой папки
     (index.html, manifest.webmanifest, sw.js и папку icons целиком).
  3) Settings -> Pages -> Branch: main, папка / (root) -> Save.
  4) Через 1-2 минуты приложение будет по адресу
     https://ВАШЕ-ИМЯ.github.io/grumi/

2. УСТАНОВИТЬ НА ТЕЛЕФОН
  Android (Chrome): откройте адрес -> меню (три точки) -> «Установить приложение»
     или в самом приложении: Для родителей -> Настройки -> «Установить на экран телефона».
  iPhone (Safari): «Поделиться» -> «На экран “Домой”».
  Иконка Груми появится на главном экране, запуск без строки браузера.

3. КАК ОБНОВЛЯТЬ
  Замените файл index.html в репозитории (Add file -> Upload files, Commit).
  Через 1-2 минуты при следующем запуске приложение само возьмёт новую версию.
  Если приложение долго было открытым: Для родителей -> Настройки -> «Проверить обновление».
  Переустанавливать приложение не нужно. Остальные файлы меняются редко.
  Сохранённые данные при обновлении не теряются.

4. ПЕРЕНОС ДАННЫХ СО СТАРОЙ ВЕРСИИ
  Прогресс хранится отдельно для каждого адреса. Перед переходом:
  в старой версии: Для родителей -> Настройки -> «Сохранить в файл»;
  в новой: Для родителей -> Настройки -> «Загрузить из файла».
  На iPhone данные из вкладки Safari и из иконки на экране тоже раздельные:
  переносите через файл.

5. ЗВУК
  Браузер включает звук только после первого касания экрана — так устроены все телефоны.

6. ВАЖНО: id в manifest.webmanifest
  Строка "id": "/grumi/" делает приложение уникальным среди ваших приложений на github.io.
  Если репозиторий называется иначе, замените grumi на его имя. У каждого приложения id должен быть свой,
  иначе Chrome считает их одним приложением и не предлагает установку второго.

7. ЕСЛИ ЧТО-ТО НЕ ТАК
  - Не предлагает установку: откройте адрес именно в Chrome (Android) или Safari (iPhone).
  - Обновление не приходит: закройте приложение полностью и откройте снова.
  - Резервная копия: делайте «Сохранить в файл» раз в неделю.
